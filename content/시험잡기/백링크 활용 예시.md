# 백링크 활용 예시

이 문서는 Obsidian의 위키 링크와 Quartz의 Backlinks 패널이 어떻게 연결되는지 확인하기 위한 예시입니다.

## 핵심 개념

백링크는 현재 문서를 링크하고 있는 다른 문서를 자동으로 보여주는 기능입니다. 문서 안에서 별도로 백링크 목록을 작성할 필요는 없습니다.

예를 들어 이 문서가 [[표준 Markdown 예시]]를 링크하면, [[표준 Markdown 예시]] 페이지의 Backlinks 영역에 이 문서가 표시됩니다.

## 위키 링크 예시

같은 블로그 안의 다른 글은 다음처럼 연결할 수 있습니다.

- [[표준 Markdown 예시]]
- [[테스트]]
- [[중간 테스트]]

표시 이름을 바꾸고 싶으면 파이프 문법을 사용할 수 있습니다.

- [[표준 Markdown 예시|Markdown 작성 규칙 예시]]
- [[테스트|테스트 글로 이동]]

## 활용 패턴

### 1. 개념 노트 연결

반복해서 등장하는 개념은 별도 문서로 만들고, 관련 글에서 계속 링크합니다.

예시:

- 경제 성장에 대한 글에서 [[성장률]]을 링크
- 인플레이션 글에서 [[물가]]를 링크
- 금리 글에서 [[중앙은행]]을 링크

이렇게 작성하면 각 개념 문서의 Backlinks 영역에서 그 개념이 언급된 글을 모아볼 수 있습니다.

### 2. 시리즈 글 연결

연속된 글은 이전 글과 다음 글을 직접 링크하고, 상위 주제 문서를 함께 링크합니다.

예시:

- 이 글은 [[표준 Markdown 예시]]의 후속 테스트 문서입니다.
- 관련 주제는 [[테스트]] 문서에서 계속 모읍니다.

### 3. 글쓰기 중 연결 후보 남기기

아직 문서가 없어도 위키 링크를 먼저 남길 수 있습니다.

예시:

- [[작성 예정인 개념 노트]]
- [[나중에 정리할 참고문헌]]

나중에 해당 문서를 만들면 기존 링크가 자동으로 연결됩니다.

## 확인 방법

1. 이 문서를 발행합니다.
2. Quartz 사이트에서 [[표준 Markdown 예시]] 페이지를 엽니다.
3. 오른쪽 Backlinks 영역에 `백링크 활용 예시`가 표시되는지 확인합니다.

## 작성 원칙

- 글 본문에서는 독자가 실제로 이동하면 좋은 문서만 링크합니다.
- 태그는 큰 분류에 사용하고, 위키 링크는 구체적인 개념 연결에 사용합니다.
- 중요한 개념 문서는 짧게라도 따로 만들어두면, 시간이 지나면서 백링크가 자연스럽게 지식 지도 역할을 합니다.
